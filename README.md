# 🌿 Plant Disease Detection App

This is a Deep Learning based Plant Disease Detection system using ResNet50.

## 🚀 Features
- Upload leaf image
- Detect plant disease
- Shows confidence score

## 🧠 Tech Stack
- Streamlit
- TensorFlow
- Keras
- Python

## ▶ Run Locally
```bash
streamlit run app.py
